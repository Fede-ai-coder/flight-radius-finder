This repository is for the Flight Radius Finder project only.

Rules:
- Do NOT reference or modify any external project (including APEX).
- Keep architecture simple and modular.
- Build an MVP first, not a production-ready system.
- Prefer clarity over complexity.
- Use mock data before integrating real APIs.

Goal:
Allow users to select a geographic area, choose a radius, and find flights to a destination from all airports within that radius.
